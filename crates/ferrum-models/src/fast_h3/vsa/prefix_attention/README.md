# Dense prefix in the fixed FP4 VSA path

`FastH3PrefixAttentionSource::prepare` accepts a checked tile-128 layout and the transformer geometry. Inputs are BF16 tiled Q, K and V `[B,padded_rows,H*D]` after Q/K normalization and rotary embedding. Outputs are the attended BF16 prefix `[B,prefix_rows,H*D]`, including prefix padding query slots, and the original centered K `[B,padded_rows,H*D]` before FP8 roundtrip. The latter is the same admitted tensor used inside this graph and feeds the video FP4 branch when composed; it is not recomputed. This component does not replace the video suffix sparse attention or assemble the complete block.

The graph centers all padded K rows with the existing explicit BF16 mean/subtraction boundary. It gathers the complete prefix Q range and performs the per-token/per-head E4M3FN roundtrip. Centered K uses the shared indexed head-roundtrip operation: the original valid-row map selects complete heads before their independent arithmetic, producing the same quantized valid rows without a full padded quantized-K intermediate. Original V uses the same valid-row map. Read-only leading-batch views expose the cross-attention rank-2 boundary; the final result is viewed as rank three. There is no host tensor bridge between operations.

The two immutable I32 maps retain ordinary Core Stored owners. K and V share one physical valid-row map and one upload; Q uses a separate contiguous prefix map. `ValidTileRows` differs from `Untile`: compacted keys retain tile order rather than original packed order. `PrefixQueryRows` and `VideoQueryRows` preserve padded query slots. Failed preparation, including refusal of the second Host allocation, releases the first map.

The FP8 operator keeps the zero-scale inverse rule. No epsilon floor or replacement scale is introduced. The pinned source uses amax/448, reciprocal, F32 scaling, E4M3FN RNE/saturate-finite conversion, F32 dequantization and final BF16 RNE. CUDA explicitly uses `div.full.f32` without FTZ; Reference uses RN F32 division. They have distinct provider fingerprints. Subnormal scales and nonfinite inputs follow the declared operator behavior; finite zero lanes can become NaN if a tiny nonzero scale makes the inverse overflow.

Attention arithmetic is explicit. The default `ReferenceSequential` uses the existing sequential F32 cross-attention contract. `with_attention_arithmetic(VendorFused, limits)` selects a separate numerical profile and the existing vendor-fused contract. CUDA callers provide `CudaCudnnConfig`, `CudnnSdpaPlanPolicy` and use the existing `cuda_vnext_tensor_providers_with_cudnn_cross_attention` factory, including its companion contracts. All plans, binding caches and workspace retain their existing charged ownership. Unsupported geometry or insufficient capacity fails; there is no implicit numerical fallback. The existing cuDNN provider currently accepts head dimensions 72 and 128.

The reusable CPU/CUDA fixture uses the real mixed-reference tile layout, two batches, head dimension 128, nonzero Q/K, an independent code-table FP8 oracle and FP64 dot/exp/PV. Its predeclared finite positive output bound is two BF16 ULP, with repeated output and retirement checks. The standalone FP8 fixture separately covers dyadic scales, E4M3 codes and ties, signed zero, tiny scales and NaN/Inf classes. These component criteria do not establish upstream bit parity, complete-model output quality or performance.
