# Ferrum 当前目标：完成 0.13.0 正式交付

**吞吐优化和默认配置已合并主分支；0.13.0 尚未发布，正式发布与公开安装核验仍待完成。** 本轮先交付已验证的吞吐改进，TTFT、TPOT、可见 ITL 的联合优化留到下一版本。

## 1. 当前目标与已完成范围

普通 `ferrum run` / `ferrum serve` 按模型声明、实际设备和内存选择已获资格的默认策略，无需用户拼接性能参数；显式配置、数值参考路径及不满足资格时的回退保留。

RTX 5090、Qwen3.8-27B 的正式吞吐验收已完成。以下按 C4 / C8 / C16 / C32 排列，使用各自同权重、同冻结 ShareGPT 负载的对照：

- **GGUF / llama.cpp：105.36% / 122.23% / 141.89% / 152.96%。** 四档均超过对照吞吐。
- **CT INT4 / vLLM：90.09% / 83.73% / 89.12% / 80.84%。** 四档按总输出 token / 总正式时长汇总达到 80%；C32 第二轮为 **78.91%**，不代表每轮稳定达标。

每格每侧 200 正式请求 × 2，另有每轮 8 次预热，零协议错误。多档延迟 SLO 仍失败；吞吐达标不等于 SLO 或全部回答质量达标。完整主表、六项延迟分位、内存、配置差异、质量及限制统一见[结果与决定](performance-popular-models-p0.zh.md)，本页不重复原始记录。

## 2. 本轮完成条件

1. 保留既有数值、质量、容量、安全及 `run` / `serve` 验证要求；最终发布包完成所声明范围的验收，已知限制与实际失败如实披露。
2. 正式发布 **0.13.0**，提供对应平台的原始发行包、校验信息和简洁发布说明，说明默认行为变化、实际验证范围及未通过的 SLO。
3. 对公开发布后的安装渠道按已声明的平台与后端核验，包括 Cargo、Homebrew、macOS/Linux 与 Windows 安装入口；确认安装到正确版本且基本运行可用。

上述正式发布和公开安装核验完成前，本目标保持进行中。既有吞吐与质量验收不因发布编排问题重复扩测，也不以准备工作代替实际交付。

## 3. 下一版本边界

长期目标仍是：**在满足事先声明的 TTFT、TPOT、可见 ITL SLO 下最大化输出吞吐。** 下一版再推进吞吐与三项延迟的联合优化；保留当前失败，不事后放宽阈值。可见 ITL 继续按相邻非空 SSE 文本事件计算，披露传输合并，不能丢弃可见停顿。

本轮不恢复 35B、Metal 扩展矩阵，不追加模型或性能门槛。后续范围另按证据确定；Metal 仍只与 llama.cpp 对照，vLLM 仅在 CUDA 比较。测试与基准复用 Rust 工具，详细命令、日志、性能与质量原件保存在仓库外。
